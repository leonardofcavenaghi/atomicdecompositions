# gwflags — quick instructions for the new functionality

Requirements: Python ≥ 3.9 with `sympy` and `mpmath`
(`pip install sympy mpmath`).  Run everything from the repository
root. General CLI/GUI usage is in [cli.md](cli.md); this file covers
what is **new since the last sync**.

## 0. Sanity check

Each suite is a plain script (pytest works too, if you have it):

```bash
python3 tests/test_gwflags.py             # core engine
python3 tests/test_bundles.py             # bundle twists       (new)
python3 tests/test_gkm_engine.py          # GKM second engine   (new)
python3 tests/test_quantum_connection.py  # QDE asymptotics     (new)
```

## 1. Complete intersections in homogeneous bundles (tautological Q, S*, sums, twists…)

Bundles are built from `gwflags.bundles` and passed anywhere the old
`K` (list of multidegree rows) was accepted — `gw`,
`small_quantum_multiplication`, `fano_index_and_betas`:

```python
from gwflags import FlagVariety
from gwflags.bundles import O, taut_sub, taut_quot, dual, osum, tensor, sym, wedge

X = FlagVariety('A4', [2])            # Gr(2,5); [2] = kept simple roots (notebook's m)
E = taut_quot(X, 2)                   # tautological quotient Q at node 2
fano, betas = X.fano_index_and_betas(E)
M, Gr, idx = X.small_quantum_multiplication(E, betas)   # c1* of Z(Gr(2,5), Q) = P^3
```

Constructors: `O(X, a1, a2, ...)` (line bundle), `taut_sub(X, node)`,
`taut_quot(X, node)`, `dual(E)`, `osum(E1, E2, ...)`, `tensor(E1, E2)`,
`sym(p, E)`, `wedge(p, E)`.  Old-style integer rows still work
(`[[3]]` = cubic).  On products, `tensor` of factor-wise bundles gives
box products.

Two things to know:

- **The tautological subbundle `S` itself is rejected** (it is not
  globally generated, so the genus-0 twisted theory does not apply);
  the error message points to `dual(taut_sub(X, node))`, whose Schur
  powers cut the classical isotropic loci —
  e.g. `sym(2, dual(taut_sub(X, 2)))` on Gr(2,5) gives OG(2,5).
- Every input is checked for **curve-wise convexity** (all splitting
  degrees ≥ 0 on rational T-curves, i.e. E globally generated on each
  invariant curve) — the honest generalization of the old "K ≥ 0"
  check.

Regressions in `tests/test_bundles.py`: Z(Gr(2,4),Q) ≅ P² and
Z(Gr(2,5),Q) ≅ P³ (twisted matrices equal the native ones
entry-for-entry), Z(Gr(2,5),Sym²S*) ≅ OG(2,5).

## 2. Second engine: Holmes–Muratore Theorem 3.4 (GKM formulation)

An independent implementation of arXiv 2509.07562, Thm 3.4 — same
invariants, different formula organization — usable as a cross-check:

```python
from gwflags import FlagVariety
from gwflags.gkm import gkm_gw

X = FlagVariety('A2', [1])                       # P^2
print(X.gw([X.pt, X.pt], (1, 0)))                # classical engine: 1
print(gkm_gw(X, [X.pt, X.pt], (1, 0)))           # GKM engine:       1
```

`gkm_gw(X, classes, beta)` takes the same Schubert classes
(`X.pt`, `X.schubert(word)`) and curve class as `X.gw`.  Scope:
untwisted, beta supported on kept nodes, beta ≠ 0.
`tests/test_gkm_engine.py` certifies exact rational agreement of the
two engines' raw localization sums (evaluated at the same random torus
point) on a battery of untwisted cases: P², Fl(3), Gr(2,4), SO(5)/B,
P²×P².

## 3. Quantum-connection asymptotics (Kontsevich dimensions)

For any variety in the battery (or your own `(algebra, keep, K)`), the
formal-solution exponents of ∇ = d/du + K/u² + G/u and the dimension
candidates −2·min Re(s) per spectral sector:

```bash
python3 benchmarks/dimension_sweep.py cubic3     # one case, ~0.3 s
python3 benchmarks/dimension_sweep.py            # whole battery
```

Python API, from the quantum matrix at y = 1 and the grading diagonal:

```python
from gwflags.quantum_connection import spectral_exponents
res = spectral_exponents(Km, Gm)   # {z: {'multiplicity', 'exponents', 'dimension'}}
```

Results and interpretation (GM-20 K3 confirmation, the lower-Serre
7/3 result, the A₃ small-locus caveat, …):
`reports/dimension_report.pdf`; table regenerated by
`python3 reports/make_dimension_table.py`.

## 4. Cross-validation against GKMtools.jl

`benchmarks/gkmtools_cross/` holds the harness for comparing against
Holmes–Muratore's Julia package (branch `GKMtest` of
mgemath/GKMtools.jl): `export_ours.py` writes our exact
characteristic polynomials of c₁⋆ at y=1
(`ours_for_gkmtools.json`), `compare_one.jl` computes theirs at q=1,
t→0 (`julia --project=<env> compare_one.jl P2|Fl3|Gr24|SO5B|G2P1_S2`).
Verified exact matches so far: P² (x³−27), Gr(2,4) (x⁶−1024x²),
G₂/P₁ (x⁶−12500x).  Their convention: `indices_of_S` lists the simple
roots *inside* the parabolic — the complement of our `keep`.
