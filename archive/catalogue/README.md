# Historical catalogue sources

| File | Role |
|---|---|
| [catalog_cache.json](catalog_cache.json) | Computation-cache snapshot used by earlier catalogue generators |
| [old_catalog.md.txt](old_catalog.md.txt) | Raw historical source of the earlier combined catalogue document |

The current [universal catalogue](../../docs/catalog/index.md) and [exact datasets](../../docs/catalog/datasets.md) provide the maintained examples, input conventions and mathematical scope. These historical files are preserved for source comparison and are not used to build the website or certify a current result.

The maintained Fanography input definitions remain at [`catalog_inputs.py`](../../catalog_inputs.py) and [`catalog_inputs.json`](../../catalog_inputs.json), where the current validators and tests import them.
