# Complete intersection in \(\mathbb P_{\mathbb P^{3}}(\mathcal O\oplus \mathcal O(1)^{\oplus 2})\)

**Geometric presentation.** Ambient variety: \(\mathbb P_{\mathbb P^{3}}(\mathcal O\oplus \mathcal O(1)^{\oplus 2})\), in the quotient convention. With \(H\) the pullback of the base hyperplane class and \(\xi=c_1(\mathcal O(1))\), the defining divisors are \(2\xi\).

Source identifier: **CKP-145**; see [CKP and HLM terminology](../sources.md). [Geometric identification](../sources.md#geometric-identification).
