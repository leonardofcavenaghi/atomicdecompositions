    Exact datasets¶

    Download the exact inputs and results underlying the catalogue. Each dataset retains its coordinate conventions, ordered bases, gradings and specialization data.

    The id field is a stable machine key for cross-referencing computations. It has no mathematical meaning; geometric names identify examples on the site.

    Dataset Records Contents
    Original exact matrix dataset 131 Root-system and bundle inputs, curve lists, symbolic and y=1 matrices, Schubert bases and grading
    Toric fourfolds 96 Fans, defining divisors, Novikov divisors, sparse exact symbolic matrices, ordered ambient bases and grading
    Toric fivefolds 72 Same fan/divisor contract, with construction data and connection analysis
    Spectra and regularized exponent multisets 302 Monic factors of the first-Chern operator, exact parameter points, unit cyclic determinants and computed multisets per eigenvalue
    Toric connection exports 168 Original power and residue-class data, with the negative-operator convention retained for export compatibility
    Additional homogeneous fourfolds 3 Exact matrices, automatic curves, Schubert bases, cyclic determinants, connection multisets and generic atomic invariants
    Atomic Hodge invariants 302 Full Hodge data, exact point tests, determinants, factor scope and certified atomic polynomials
    Universal catalogue index 302 Canonical record links, dimension, recorded index, matrix rank and search terms

    The fourfold computation notes and fivefold computation notes retain their original characteristic-factor convention. Use spectral-data.json for the catalogue’s factor and exponent values; connection-exponents.json retains the original export schema. The displayed catalogue and the spectral dataset use A=c1(TX)⋆ A = c 1 ( T X ) ⋆ throughout; the notation key explains the sign conversion.

    Sources for the fourfold constructions include Coates–Kasprzyk–Prince, 1409.5030v3, and Hausen–Laface–Mauz, 1907.08000v3. CKP identifiers denote period buckets; equality of periods does not identify varieties up to isomorphism. The fivefold page describes its constructions.

    The matrices act on the returned ambient sector. Their columns are images of the ordered basis; grading and Novikov maps are part of the data. Full Hodge numbers do not supply missing primitive quantum operators. Use the root-system or fan/divisor mathematical conventions for the relevant presentation, and the version-specific software guides to reproduce its input.

    Dataset usage gives a Python example for reading the exact matrices and their conventions.

    Exponent multisets apply separately at each eigenvalue, with multiplicities retained. The spectral dataset includes the connection analysis of the original flag matrices as well as the toric and additional homogeneous examples. A null exponent field supplies no value; it never denotes an empty multiset. Each record states its own parameter point, which can differ from the point used for its atomic Hodge data.

    Full atomic Hodge polynomials require unit cyclicity, identification of the entire Hodge-invariant sector and a justified primitive-cohomology assignment. The atomic invariants state the hypotheses and distinguish full decompositions from partial ambient information.
