    Flag varieties and sections¶

    These entries include orthogonal, symplectic, exceptional and partial flag varieties, and complete intersections in them. Each displayed matrix comes from exact gwflags virtual localization using the full automatically supported curve list.

    For a worked full-flag example, see Fl(1,2,3).

    Matrices represent multiplication by c1(TY) c 1 ( T Y ) on the returned ambient sector, with every Novikov variable set to 1 1 . Columns are inputs and rows are outputs. The ordered basis below uses reduced Schubert words; () is the unit. Basis indices in the download are zero-based.

    Download all symbolic matrices, bases, gradings and curve classes or browse Download matrices and inputs. See How to Use for input conventions.
