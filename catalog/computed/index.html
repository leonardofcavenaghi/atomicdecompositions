    Download matrices and inputs¶

    This download lets you reuse the matrices displayed in the catalog in Python, SageMath or other software, or repeat the computations from their original inputs. It includes the basis order and grading needed to interpret each matrix.

    You can read the examples directly in the catalog; the download is optional. Exact means that fractions and symbolic expressions are preserved instead of rounded decimal approximations.

    The fano_index field uses the software’s ambient Chern-lattice convention; it need not be the intrinsic Fano index of a low-dimensional section. For example, a conic is P1 with geometric index 2 even when the ambient gcd is 1. See catalog conventions.

    Download the complete JSON dataset

    Each record contains the executable algebra/kept-root/bundle input, the full automatically supported curve list in ambient coordinates, the symbolic c1(TY) c 1 ( T Y ) multiplication matrix, its specialization at all yi=1 y i = 1 , the ordered Schubert basis, and the grading. Rational numbers are stored as exact strings. The matrix acts on the returned ambient sector, with columns as inputs and rows as outputs.

    These are the same results displayed in the catalog. See Methods and conventions for their mathematical scope.

    Use the exact dataset¶

    import json
from pathlib import Path

data = json.loads(Path("localization-results.json").read_text())
example = next(r for r in data["examples"]
               if r["title"] == "P4  Fano index 5")
print(example["input"])
print(example["matrix_symbolic"])
print(example["basis_words"])

    To recompute a record, construct FlagVariety with its algebra and kept roots, parse its bundle using the documented input syntax, and call small_quantum_multiplication(K) without restricting the automatic curve list.
