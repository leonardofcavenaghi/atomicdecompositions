# Historical utilities and catalogue sources

This directory preserves earlier catalogue generators, source-editing utilities and catalogue snapshots. These files are historical reference material; the supported software and mathematical results are documented in the [repository overview](../README.md).

| Collection | Contents |
|---|---|
| [Legacy tools](legacy-tools/README.md) | Earlier Python utilities and browser diagnostics, grouped by purpose |
| [Catalogue sources](catalogue/README.md) | Raw earlier catalogue text and computation-cache snapshot |

Current catalogue generation and validation use the maintained tools in [`scripts/`](../scripts/), the exact datasets in [`docs/data/`](../docs/data/), and the procedures in [Contributing](../CONTRIBUTING.md). The historical scripts are not part of the installation, test suite or website build. Their original file contents are preserved; embedded paths and assumptions may refer to an earlier repository layout.
