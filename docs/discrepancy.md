# Reference discrepancies

The independent reference campaign records two adjudicated discrepancies. The V₈ corner entry in the imported reference has a factor-of-two error; the quantum-period calculation gives `T = 56`. The Fl(1,2,5)/GM-20 reference agrees through curve degree 4 after the documented degree-3 basis change but omits nonzero degree-5 classes. These are reference-data limitations, not software failures.
