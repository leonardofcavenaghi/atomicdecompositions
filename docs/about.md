# About GEOATOMS

GEOATOMS develops computational tools and examples in algebraic and
enumerative geometry, with a focus on quantum cohomology of flag and toric varieties.

## Software and sources

The open-source [gwflags repository](https://github.com/leonardofcavenaghi/atomicdecompositions)
contains the localization algorithms, tests and catalog-generation tools.
AI coding tools, including Google Antigravity, have assisted software and
website development under the contributors’ mathematical supervision.

The threefold classification follows [Fanography](https://www.fanography.info/).
The mathematical formulas, conventions and verification procedures are
described in the [flag methods](methodology.md) and [toric methods](toric/mathematics.md).
