# GEOATOMS contributor instructions

Follow [AGENTS.md](AGENTS.md) and [Contributing](CONTRIBUTING.md) for mathematical, software and documentation changes. The [repository map](docs/development/repository-map.md) identifies maintained sources and historical material; the [maintenance guide](docs/development/maintenance.md) gives supported validation and publication commands.

Use the selected distribution's documented environment and input conventions. Base mathematical regression expectations on independent reference values or identities. Preserve exact arithmetic, ordered bases, gradings, curve-completeness assumptions and the distinction between ambient operators and full cohomology.
