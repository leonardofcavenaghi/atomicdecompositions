    Fanography 3-Folds¶

    This section records the 105 smooth Fano threefold families from Fanography. Entries with supported flag-variety inputs include computed ambient matrices; entries marked Catalog only have reference descriptions without a computed matrix.

    Realization types. Entries labelled direct flag variety or complete intersection can be entered in gwflags. Homogeneous-bundle entries require the corresponding bundle constructor. Catalog-only entries link to reference information; no executable input or computed matrix is provided here.

    Fano Variety 1-1¶

    1-1

    Description: Double cover / weighted degree-6 hypersurface (Fanography). Realization type: Catalog only — not represented by the current gwflags flag-variety/ordinary complete-intersection input model.
