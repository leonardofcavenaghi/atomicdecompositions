# Development and maintenance

The repository contains the flag localization package, versioned flag and toric distributions, exact mathematical datasets, and the documentation website.

- [Repository map](repository-map.md): where each source, dataset and supporting tool belongs.
- [Maintenance guide](maintenance.md): update a computation, regenerate supported catalogue pages, validate a distribution and publish documentation.
- [Contributing](https://github.com/leonardofcavenaghi/atomicdecompositions/blob/main/CONTRIBUTING.md): environment setup and requirements for a change.

For use of the software, start with [installation](../installation.md) and the [version-specific guides](../software/index.md). Mathematical conventions are described in [localization on flag varieties](../methodology.md), [localization on toric varieties](../toric/mathematics.md) and [atomic invariants](../catalog/atomic-invariants.md).
